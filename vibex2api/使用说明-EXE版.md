# vibex2api 使用说明（EXE 免安装版）

一个文件搞定：`vibex2api.exe`（约 14MB）——**不需要装 Python、不需要装任何东西**。

---

## 三步开始

**第 1 步：双击 `vibex2api.exe`**
（杀毒软件如果拦截，选择"允许运行"——打包软件的常见误报）

**第 2 步：第一次启动会提示你填 KEY（约 1 分钟）**

黑窗口里会显示获取方法，照做：

1. 浏览器打开 **https://vibex.runninghub.cn**，用手机号注册/登录（免费，送额度）
2. 按 `F12` → 顶部选 **Application**（应用）→ 左侧 **Local Storage**（本地存储）→ 点开该网站
3. 找到 **`Rh-Accesstoken`** 这一行，双击它的值，全选复制（一长串字符，中间有两个点）
4. 回到黑窗口，**粘贴，回车**

看到 `token 已保存到 vibex2api.config.json` 就成功了。以后双击不再要求填写。

**第 3 步：看到这行就是服务跑起来了**

```
======== Running on http://127.0.0.1:8787 ========
```

保持黑窗口开着（关窗口 = 停服务）。

---

## 怎么用

在任何支持 OpenAI 的软件/客户端里填：

| 填什么 | 值 |
|---|---|
| API 地址（Base URL） | `http://127.0.0.1:8787/v1` |
| API Key | 随便填（如 `sk-any`） |
| 模型名（免费档推荐） | `free-qwen-3.8-flash-next`、`free-deepseek-v4.1-flash`、`free-glm-5.2`、`free-qwen-3.8-max` |

全部 18 个模型名单：浏览器打开 `http://127.0.0.1:8787/v1/models` 查看。
（模型名单里的 `0` 是豆包通道、`pro-0`/`lite-paid`/`paid-*` 是付费档——免费档认准 `free-` 开头）

## 常见问题

- **回复很慢（30 秒~5 分钟）**：正常。背后是 Claude Code agent 完整跑一轮，不是普通聊天 API。
- **模型自称"我是 Claude"**：平台系统提示词的固定话术，不影响使用。
- **KEY 约 30 天过期**（提示 401/token 无效）：按第 2 步重新拿一次，双击 exe 再粘一次即可；
  或直接用记事本打开 exe 旁边的 `vibex2api.config.json`，替换 `token` 字段。
- **想开机自启/后台常驻**：把 exe 快捷方式放进"启动"文件夹（Win+R → `shell:startup`）。
- **免费额度**：按"结算周调用次数"计，新账号日常轻度使用一般够用；平台宣传"每日百亿 Token"是营销话术。
- **免责**：非官方用法，请用自己的账号，注意平台协议风险。
