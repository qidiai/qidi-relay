================================================
  笔记本 AtomCode 账号推送说明（一分钟搞定）
================================================

【做什么】
把笔记本上登录的 AtomCode 账号推送给台式机的代理，
代理就能双账号自动轮换，多一份配额。

【怎么跑】在笔记本上打开 PowerShell（开始菜单搜 powershell），
复制下面这一行，回车：

py -3 "\\192.168.1.<IP>\程序开发\本地局域网中转-v3\push_atomcode_auth.py" --to http://192.168.1.<IP>:8765 --label 小号

【看到什么算成功】
[成功] 已添加账号「小号」（user=xxxx，代理现有 2 个账号）

【然后呢】
打开 http://192.168.1.<IP>:8765 面板，「外部账号」卡片里
能看到 主号 + 小号 两个 AtomCode 账号，请求自动轮换。
笔记本上的官方 AtomCode 客户端可以退出登录了。

------------------------------------------------
常见问题：

1. py -3 报错不认识 → 换 python 试试：
   python "\\192.168.1.<IP>\程序开发\本地局域网中转-v3\push_atomcode_auth.py" --to http://192.168.1.<IP>:8765 --label 小号

2. 找不到 auth.toml → 先在笔记本上打开官方 AtomCode 客户端
   登录一次（登录后自动生成该文件），再跑上面的命令。

3. auth.toml 已经拷到别处了 → 加 --file 参数指定路径：
   py -3 push_atomcode_auth.py --to http://192.168.1.<IP>:8765 --label 小号 --file "C:\Users\你\.atomcode\auth.toml"

4. 弹出账号密码框 → 输台式机的用户名和密码，勾选记住凭据。

5. 跑完想换备注名/重新推 → 同一个命令再跑一次就是更新。
