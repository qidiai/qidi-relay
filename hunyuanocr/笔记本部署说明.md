# HunyuanOCR 笔记本部署（3 步搞定）

模型已在台式机共享目录里，笔记本拷过来即可（约 1.6GB，千兆内网 <1 分钟）。

## 部署步骤

**第 1 步：拷贝模型+脚本**（笔记本上开 PowerShell）：

```powershell
xcopy "\\192.168.1.<IP>\程序开发\本地局域网中转-v3\hunyuanocr" "C:\hyocr\" /E /I
```

（只拷 models\ 两个 .gguf + start_hyocr_laptop.ps1 即可，README 可选）

**第 2 步：装 llama.cpp**（一次性，约 30 秒）：

```powershell
winget install ggml.llamacpp
```

**第 3 步：启动**：

```powershell
powershell -ExecutionPolicy Bypass -File C:\hyocr\start_hyocr_laptop.ps1
```

脚本自动探测显卡：
- 有 NVIDIA / AMD / Intel Arc → Vulkan 加速（-ngl 99），每页约 5~30 秒
- 只有老核显 → 纯 CPU，速度取决于笔记本 CPU 核数（现代 8 核以上比台式机 E3 快 2~4 倍）
- 万一 Vulkan 崩（ErrorDeviceLost）→ 按脚本末尾注释改回纯 CPU

## 验证

```powershell
curl http://127.0.0.1:8899/health
```

返回 `{"status":"ok"}` 即成功。之后跟台式机一样用 OpenAI 兼容接口调 model=hunyuanocr。

## 可选：让笔记本反过来给全局域网供 OCR

笔记本服务默认监听 0.0.0.0:8899。想把它也注册进中转（作为第二个 OCR 节点），在台式机的中转 config.json 里加：

```json
"hunyuanocr-laptop": {
  "base_url": "http://192.168.1.xxx:8899/v1",
  "models": ["hunyuanocr"],
  "api_keys": ["local-llamacpp-noauth"],
  "_comment": "笔记本 HunyuanOCR 节点"
}
```

（config 热读生效，无需重启中转；xxx 为笔记本实际 IP）

## 速度预期

| 环境 | 每页耗时（A4 中文页） |
|---|---|
| 台式机 E3-1230 v3 纯CPU（现状） | 4~10 分钟 |
| 笔记本现代 CPU 8核+ 纯CPU | 1.5~4 分钟 |
| 笔记本 + NVIDIA/AMD 独显 Vulkan | 5~30 秒 |

衡量标准：跑同一张 ocrtest\smoke.png（在台式机共享的 qidicode 工作区）对比耗时即可。

## ✅ 部署完成（2026-09-26，方案升级为 CUDA 版）

实际部署与本文原 winget/Vulkan 方案不同，实测更优，以下为落地形态：

- **引擎**：复用笔记本现成的 PrismML llama.cpp CUDA 构建（`F:\Bonsai\Bonsai-demo\bin\cuda\llama-server.exe`），**无需 winget 安装**
- **模型**：本地副本 `C:\hyocr\models\`（Q8_0 578MB + bf16 mmproj 997MB），不依赖台式机共享在线
- **实测**（2026-09-26）：1328² 密集中文标注图 7.4s 稳态（台式机 CPU 同图 >17s）；同图复跑 0.76s（KV 缓存命中）；**Q8 量化 mmproj 在此 GPU 实测反而慢 28%，已弃用**（官方 Q8 mmproj 留在 `F:\AI\mmproj-HunyuanOCR-Q8_0.gguf` 备查）
- **注册**：台式机中转(8765) `providers.hunyuanocr` 已指向 `http://192.168.1.<IP>:8899/v1`（笔记本为主力）；台式机本机服务改由 `model=hunyuanocr-desktop` 调用（fallback，实测路由通过）。config 热重载已生效，端到端双路由验证 PASS（2026-09-26 02:19：主力 2.4s / fallback 17.5s，文字识别均全对）
- **自启**：笔记本 Startup 目录 `autostart_hyocr_cuda.vbs`（删除即取消自启）；启动脚本 `C:\hyocr\start_hyocr_cuda.ps1`（share 内有同源副本）
- **⚠️ 显存纪律**：本节点常驻占 ~4.7GB/6GB 显存。要跑 ComfyUI 出图（峰值同量级）时先 `C:\hyocr\stop_hyocr.ps1`；用户 2026-09-26 决策：**任务冲突时以笔记本 OCR 为主**
